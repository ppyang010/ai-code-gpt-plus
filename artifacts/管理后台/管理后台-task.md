# 管理后台 任务跟踪

最后更新：2026-05-31

## 说明

- 本文件用于跟踪 `管理后台` 的具体执行任务。
- 本文件基于 `管理后台-desgin.md` 拆分具体执行任务。
- `管理后台-desgin.md` 负责沉淀需求定义、设计边界、代码落点和实施计划；本文档负责执行拆分、进度状态、阻塞项和下一步。
- 配套设计文档：`管理后台-desgin.md`
- 配套预留功能文档：`管理后台-预留功能.md`
- 任务执行过程中，任务状态、阻塞项、优先级和下一步必须随着进度同步更新。
- 若需求目标、边界、接口、字段、数据结构、实现顺序、验收口径、任务优先级或范围出现变动，先更新 `管理后台-desgin.md`，再同步本文档；若执行中发现变动已经影响设计结论，也必须回写设计文档。

## 当前阶段

当前处于：`阶段 B：计划产出，等待按任务拆分进入实现`

已具备：

- 后端已有 `CommonResponse<T>`、`PageResponse<T>`、MyBatis-Plus 分页、统一异常和中文错误提示基础。
- 后端已有 `app_user`、`model_provider`、`model_config`、`api_call_log`、`user_token_usage`、`user_balance` 表。
- 前端已有 Vue 3、Vite、TypeScript、Pinia、Vue Router、TDesign Vue Next。
- 用户侧聊天页和模型列表接口已存在，后台可与其隔离扩展。

尚未完成：

- 后台管理员身份、登录和后台 token 鉴权。
- 管理用户管理。
- 普通用户管理。
- 模型供应商后台 CRUD。
- 模型配置后台 CRUD。
- 提示词模板表和后台 CRUD。
- 调用日志和用量统计后台只读页面。
- 后台前端路由、布局、页面和请求封装。

- 每次开始一个明确任务前，确认或补充对应任务项。
