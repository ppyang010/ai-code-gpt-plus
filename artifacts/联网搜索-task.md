## 当前阶段

当前处于：`代码入口、契约预留字段和继续生成边界已确认，三态发送入口与后端 auto 意图规则已接入，待按设计补真实检索执行和消息 metadata 持久化`

已具备：

- 后端 `ChatMessageSendRequest` 已预留 `enableWebSearch`
- 前端已接入 `关闭 / 开启 / 自动判断` 三态入口
- `auto` 第一版已改为后端“意图规则表 + 优先级”实现，方便后续扩展
- 聊天发送、消息列表、SSE、继续生成链路都已统一收口在 `ChatMessageServiceImpl`
- `chat_message.metadata` 已是可复用 JSON 扩展位
- 前端发送入口已统一收口到 `useChatStore.sendMessage(...)`

尚未完成：

- 真实搜索供应商抽象与配置
- 后端搜索结果摘要注入
- 搜索上下文 metadata 持久化与继续生成复用
- 联网搜索真实执行、结果持久化与结果提示交互
